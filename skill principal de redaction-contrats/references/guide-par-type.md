# Guide par type de contrat

Table des matières : 1. Choisir le modèle · 2. Questions par type · 3. Points d'attention par type

## 1. Choisir le modèle

| La demande ressemble à… | Modèle (`assets/modeles/`) | Parties |
|---|---|---|
| Expert / consultant / cabinet qui livre une étude ou un conseil | `consultance.md` | Client / Consultant |
| Appui technique dans la durée, rapports périodiques, prix au temps passé | `assistance-technique.md` | Client / Prestataire |
| Former des cadres et agents (sessions, ateliers, kits, attestations) | `formation-personnel.md` | Client / Prestataire |
| Maintenance préventive et dépannage de matériels et mobiliers | `maintenance-materiels.md` | Client / Prestataire |
| Nettoyage / entretien de locaux | `entretien-locaux.md` | Client / Prestataire |
| Gardiennage / sécurité privée | `securite-privee.md` | Client / Prestataire |
| Location de bureaux ou de locaux professionnels | `bail-bureau-professionnel.md` | Bailleur / Preneur |
| Embauche pour une durée connue (date de fin fixée) | `cdd-terme-precis.md` | Employeur / Employé |
| Embauche pour un événement ou une tâche dont la fin n'est pas datée (remplacement, projet) | `cdd-terme-imprecis.md` | Employeur / Employé |
| Stagiaire diplômé qui acquiert une expérience professionnelle | `stage-qualification.md` | Organisme d'accueil / Stagiaire |
| Élève ou étudiant en cursus | `stage-ecole.md` | Organisme d'accueil / Stagiaire |
| Autre type (vente, fourniture, CDI, NDA, partenariat…) | → `contrats-hors-corpus.md` | selon le cas |

Cas hybrides : un contrat qui mêle deux logiques (ex. prestation + formation) part du modèle dominant, auquel on ajoute les articles de l'autre (voir `clauses-communes.md`). Un CDD n'est jamais un contrat de prestation : si la personne travaille sous l'autorité de l'organisation, avec horaires imposés, on est sur un contrat de travail ; si elle livre un résultat de façon autonome, sur une prestation. En cas de doute réel, poser la question à l'utilisateur.

## 2. Questions minimales par type
Ne poser que les questions dont la réponse manque ; regrouper en un seul message ; proposer des valeurs par défaut. Pour tous : parties (identité, représentant), objet précis, dates / durée, prix ou rémunération (montant, devise, HT/TTC), pays de droit applicable, secteur privé ou public.

- **Consultance / assistance** : livrables attendus, tranches de paiement, qui supporte les frais de mission, propriété des livrables.
- **Formation** : thèmes, nombre de participants, lieu, attestation et rapport, paiement avant ou après rapport.
- **Maintenance** : périodicité des visites, délai d'intervention sur appel, pièces (qui achète), liste des matériels.
- **Entretien** : horaires et fréquence, qui fournit les produits, superficie et description des locaux.
- **Sécurité** : sites, nombre de postes, horaires jour/nuit, agrément du prestataire, assurance.
- **Bail** : désignation et surface, loyer et périodicité, caution (nombre de mois), révision, qui paie l'enregistrement, usage.
- **CDD** : poste, supérieur, salaire et périodicité, horaires, durée ou événement, préavis.
- **Stage** : missions, maître de stage, indemnité, temps plein/partiel (stage-école), durée.

## 3. Points d'attention par type
- **Consultance** : paiement conditionné au « service fait » ; livrables = propriété du Client ; pas de sous-traitance sans accord ; le Consultant couvre ses propres risques.
- **Assistance technique** : la rémunération « au temps passé » exige des justificatifs (relevés de temps) : le dire clairement.
- **Formation** : séparer ce qui est dû par le Prestataire (kits, supports, attestations, rapport) de ce que le Client doit faciliter.
- **Maintenance** : distinguer ce qui est inclus (visites, interventions sur appel) du hors-contrat (pièces, facturées sur proforma) ; prévoir la fiche d'entretien signée après chaque visite.
- **Entretien** : liste de prestations « non exhaustive » ; l'annexe 1 (cahier des charges) et l'annexe 2 (locaux) sont ce qui permet de contrôler l'exécution : ne pas les laisser vides.
- **Sécurité** : le régime de responsabilité en cas de vol est le cœur du contrat ; il est lié à une **défaillance caractérisée** des gardes. Prévoir la déclaration de sinistre (48 h ouvrables) et le constat contradictoire.
- **Bail** : état des lieux contradictoire signé = annexe 1 ; la clause résolutoire doit être symétrique (recours du Preneur / recours du Bailleur) ; délais de mise en demeure à valider au regard du droit local impératif.
- **CDD** : vérifier durée maximale et renouvellement légaux ; le terme imprécis n'est admis que pour certains motifs (remplacement, tâche ponctuelle, etc.) : l'objet du recrutement doit être indiqué.
- **Stages** : aucune déclaration de gains ; protection sociale (accidents du travail) pour le stage de qualification, assurance à la charge du stagiaire pour le stage-école ; durée et préavis différents.
