# Textes de référence (catalogue)

**Origine** : textes cités dans les 12 modèles sources, tous rédigés pour le droit ivoirien / OHADA. Ils sont donnés ici comme **points de départ**, pas comme vérité à jour : une loi peut avoir été modifiée ou abrogée. Procédure : (1) si le droit applicable est celui de Côte d'Ivoire, proposer le texte correspondant ; (2) si l'outil de recherche web est disponible, vérifier la vigueur ; (3) sinon, le signaler dans la synthèse (« référence à vérifier ») ; (4) si le droit applicable est un autre pays, remplacer par un champ à compléter plutôt que d'inventer des références.

## Règle de rédaction
Dans le contrat, citer le texte sous la forme : « la loi n° … du … portant … ». Ne jamais citer un numéro d'article dont on n'est pas certain : écrire « en ses dispositions applicables ». Si aucun texte spécifique n'existe, la formule de repli est : « …et, à défaut, par le droit commun des contrats applicable en [pays] ».
